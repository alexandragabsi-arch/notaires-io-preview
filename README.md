# Notaires.io — Preview

Maquette statique de **Notaires.io**, plateforme de prise de rendez-vous notarial intelligente.

## Démo en ligne

→ Déployée sur Vercel : voir le lien dans Settings → Deployments.

## Contenu

Single HTML file (`index.html`) qui contient :
- Landing complète (hero, comment ça marche, features, comparatif, témoignages, pricing notaires, FAQ, footer)
- Wizard de prise de RDV : 3 questions de routage + 4 questions d'enrichissement optionnelles
- Mockup d'email reçu par le client
- Visite guidée interactive de l'espace notaire (6 slides)

## Stack
- HTML / CSS / JavaScript vanilla
- Aucune dépendance, aucun build
- Polices via Google Fonts (Playfair Display + Inter)

## Local
```bash
python3 -m http.server 5180
```
Puis ouvrir [http://localhost:5180](http://localhost:5180).
